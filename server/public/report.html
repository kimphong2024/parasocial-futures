How to read this

The report is written by Claude from the human-approved library, then cached; it regenerates only when someone asks. Citations are filtered server-side against the evidence pack, so a citation that survives points at a signal that exists — but the prose around it is generation, and the pills are there so no claim needs to be taken on faith. Probabilities are conditional on human-set driver ranges and hand-shaped scenario conditions, not forecasts. Artifacts are shipped as a seed file rather than database rows, so they are described here but not citable the way signals and scenarios are. Method in full on the Method page.
