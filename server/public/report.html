The Report

The signal library, the futures triangle, the scenario set and the simulation, read as a single argument. Every claim cites the evidence beneath it — follow any citation to its source.

How to read this

Claude writes the report from the human-approved library, and it is then cached; it regenerates only when someone asks. Citations are filtered server-side against the evidence pack, so a citation that survives points at a signal that exists — but the prose around it is generation, and the pills are there so no claim need be taken on faith. Anything presented as a quotation is checked against retained source text and removed if it does not match. Probabilities are conditional on human-set driver ranges and hand-shaped scenario conditions, not forecasts. Artifacts ship as a seed file rather than database rows, so they are described here but not citable the way signals and scenarios are. Method in full on the Method page.
